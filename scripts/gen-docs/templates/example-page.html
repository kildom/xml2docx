<table>

Creates a table for organizing structured data in a printed document.

The <table> element is designed for predictable page layout rather than responsive web presentation. It can contain rows and cells, and can be styled with attributes such as width, border, and alignment.

Syntax

DocTML
<table [attributes]>
  <table-row>
    <table-cell>Content</table-cell>
  </table-row>
</table>

Example

A small table is often enough to demonstrate the relationship between source markup and the final document. Notice that the source stays readable even when the rendered output is intended for a fixed page.

Example
<table border="1" width="100%">
  <table-row>
    <table-cell>Product</table-cell>
    <table-cell>Price</table-cell>
    <table-cell>Quantity</table-cell>
  </table-row>
</table>

Attributes

Use table attributes when the document needs explicit geometry or visual rules. Values are interpreted by the DocTML layout engine and ultimately affect the generated page rather than a browser viewport.

AttributeTypeDescription
widthlength | percentControls the table width.
bordernumberSets the border width.
alignleft | center | rightPositions the table on the page.
spacinglengthControls space between cells.

Content

A table may contain rows, and rows may contain cells. Cells can contain normal text as well as inline elements such as <strong>, <link>, and expressions.

  • Keep the table structure shallow and predictable.
  • Prefer semantic rows and cells over visual spacing.
  • Use explicit widths when the printed layout must remain stable.
  • For complex page composition, consider a layout element instead.

Notes

Unlike an HTML table, a DocTML table is ultimately resolved against a page size, margins, and document flow. This makes properties such as width and pagination meaningful even when the same source is exported to different formats.

Related elements: <paragraph>, <heading>, <image>, and <layout>.

paragraph

A paragraph contains normal document text and participates in the document flow.

heading

A heading creates a semantic document heading with optional level and style attributes.

image

An image places an image resource into the printed document and supports explicit dimensions.

list

A list represents ordered or unordered items with predictable indentation.

layout

Layout elements provide page-level composition for columns, regions, and positioned content.
